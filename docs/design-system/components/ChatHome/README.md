# ChatHome

The full-width welcome screen for a new chat.

A greeting with one sentence that sums up what happened while the user was away, then four starter cards (`.v-starter`) for the main jobs: simulate an email, add knowledge, create a rule, review pending drafts. The composer stays at the bottom, in the same position as in a conversation, so the layout doesn't jump when the first message is sent. Starter cards disappear after the first message.
