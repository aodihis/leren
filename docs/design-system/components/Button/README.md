# Button

Actions. Labels are verbs in sentence case.

- `v-btn--primary`: one per area, for the main forward action (Approve and send, New chat).
- `v-btn--secondary`: Review, Edit, Simulate email.
- `v-btn--ghost`: low-emphasis links in card headers (View all).
- `v-btn--danger`: Reject. Outline only, never a solid red fill.
- `v-iconbtn`: toolbar icons, always with an `aria-label`. `v-send` is the composer's send button.
- Sizes are 36px by default and 30px with `--sm`.
